## Сумма через reduce

```python
from functional import total

print(total([7, -2, 10, 5]))  # 20
print(total([]))              # 0
```

`functools.reduce` последовательно применяет лямбда-функцию сложения.
Начальный аккумулятор равен нулю, поэтому пустой ввод корректен.
Принимается любой итерируемый источник целых чисел, в том числе генератор.
Исходный список не изменяется. `bool`, строки и дробные числа отклоняются.
`map` лениво проверяет элементы, `sum` в реализации не используется.

## Генератор Фибоначчи

```python
from itertools import islice
from generators import fibonacci

stream = fibonacci()
print(list(islice(stream, 6)))  # [0, 1, 1, 2, 3, 5]
print(next(stream))            # 8
```

Функция использует `yield` и хранит только два текущих числа.
Последовательность начинается с 0 и 1. Генератор бесконечный:
потребитель выбирает число элементов, не создавая весь список заранее.
После остановки выборки вычисление продолжается с прежнего места.

## Случайные числа в диапазоне

```python
from generators import random_numbers

print(list(random_numbers(1, 20, 8, seed=42)))
# [4, 1, 9, 8, 8, 5, 4, 18]
```

Это конечный генератор ровно `count` целых чисел. Обе границы включены.
Равные границы дают одно и то же значение, нулевое количество — пустой поток.
Нижняя граница не должна превышать верхнюю. Границы и количество — целые числа.

Каждый экземпляр использует отдельный `random.Random`. Одинаковый seed
даёт воспроизводимый поток; другой экземпляр и глобальный `random`
не изменяются. У функций seed по умолчанию равен `None`; командная строка
использует 42 для повторяемого примера, его можно изменить через `--seed`.
Это псевдослучайные данные для учебной демонстрации.

## Каррирование

```python
from functional import curry


def expression(a, b, c):
    return a * b + c


curried = curry(expression)
with_two = curried(2)
with_two_and_six = with_two(6)
print(with_two_and_six(3))  # 15
print(with_two_and_six(4))  # 16
print(with_two(7)(1))       # 15
```

`curry` — функция высшего порядка: получает функцию и возвращает цепочку
функций одного аргумента. Замыкания сохраняют уже переданные аргументы
в неизменяемых кортежах. Исходная функция вызывается только после последнего
аргумента. Промежуточные функции можно повторно использовать и разветвлять.
Это преобразование `f(a, b, c)` в `f(a)(b)(c)`, а не выполнение функции заранее.

Поддерживаются функции с фиксированным ненулевым числом обязательных
позиционных параметров, включая positional-only. Параметры со значениями
по умолчанию, `*args`, `**kwargs` и keyword-only явно отклоняются.
Сигнатура должна быть доступна через `inspect.signature`.
Каждый этап принимает ровно один позиционный аргумент. Типы его значения
определяет исходная функция; её исключения передаются вызывающему коду.

## Бесконечный генератор случайных данных

```python
from itertools import islice
from generators import random_data

records = random_data(10, 20, seed=9)
for row in islice(records, 5):
    print(row)  # {'number': ..., 'value': ...}
print(next(records)['number'])  # 6
```

Каждый `yield` возвращает новый словарь с порядковым номером, начиная с 1,
и случайным целым значением в заданном диапазоне. Собственного ограничения
числа записей нет. Границы проверяются так же, как у конечного генератора.
Изменение ранее выданного словаря не меняет следующие записи.

Оба бесконечных генератора нужно ограничивать через `islice` или прекращать
обход через `break`. `list(fibonacci())` и `list(random_data())` без ограничения
не завершатся. В `main.py` такие вызовы отсутствуют.

Проверки аргументов внутри генераторов выполняются при первом `next`
или начале обхода — это обычная ленивость функций с `yield`.
